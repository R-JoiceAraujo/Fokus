## 📌 Sobre o projeto

O **Fokus** é um aplicativo web criado para potencializar a produtividade dos usuários por meio da **técnica Pomodoro**: trabalhar em blocos de foco intenso, intercalados com pausas planejadas para recuperar a energia.

A interface é intuitiva e organizada em **três telas principais**:

| Modo | Duração | Objetivo |
|------|---------|----------|
| 🎯 **Foco** | 25 minutos | Sessões de concentração total |
| ☕ **Pausa curta** | 5 minutos | Descanso rápido entre as sessões |
| 🌿 **Pausa longa** | 15 minutos | Recuperação maior após ciclos de foco |

## ✨ Funcionalidades

- ⏲️ Cronômetro regressivo para cada modo
- 🔄 Alternância entre foco, pausa curta e pausa longa
- 🎨 Interface que muda de acordo com o modo selecionado
- 📱 Layout limpo e fácil de usar
