# Fokus
Projeto desenvolvido para potencializar a produtividade dos usuários, utilizando a técnica Pomodoro. O aplicativo possui uma interface intuitiva com três telas principais: uma para sessões de foco total com um cronômetro de 25 minutos, outra para intervalos curtos de 5 minutos, e uma terceira para pausas maiores de 15 minutos.
